Tubbies Monsters Adventure - iPhone offline PWA

1. Upload all files in this folder together to an HTTPS website (e.g. GitHub Pages or Netlify).
2. Open the HTTPS link in Safari on your iPhone while online.
3. Tap Share > Add to Home Screen > Add.
4. Open the Home Screen icon, allow the initial page to load completely, then you can play offline.
5. Rotate to landscape to play. iOS does not guarantee orientation lock for web apps.

Opening index.html directly from Files will not install the offline service worker.
